# Logo sources

- `crest.png`: the official school crest, supplied by the site owner (1437 x 1094 px, RGBA, transparent background, about 1.5 MB). It is the source file and is never edited. It is the only official logo asset so far.
- `crest-web.png`: a proportional downscale of `crest.png` (540 x 411 px, alpha kept, nothing else changed) that the page and the single-file bundle actually load, because the original is too heavy for a page. Its width is at least twice the largest size any slot shows it at (the 254 px intro seal), so it stays sharp on 2x screens; the size cap is 350 KB. Regenerate it after any change to `crest.png` with `sips -Z 540 crest.png --out crest-web.png`.
- The earlier website stand-ins (`logo-horizontal.png`, `logo-horizontal-white.png` and the old opaque crest crop, all taken from the school's current website as white-background images) were removed. The crest is shown in every logo slot with its own aspect ratio (`object-fit: contain`); it is never stretched, cropped or recoloured.
- `wordmark.png`: the official horizontal lockup (crest + "ASPIRE INDIAN INTERNATIONAL SCHOOL" wordmark), supplied by the site owner (2140 x 470 px, RGBA, transparent background, about 790 KB). Source file, never edited.
- `wordmark-web.png`: a proportional downscale of `wordmark.png` (900 x 197 px, about 175 KB) used in the desktop header's logo slot (src/css/header.css `.hdr__logo-d`). Regenerate with `sips -Z 900 wordmark.png --out wordmark-web.png` after any change to `wordmark.png`.

Note: the brand guide sets a minimum crest size of 60 px, and the mobile header and menu slots (31 px) are smaller than that -- they still use the emblem-only crest, since the horizontal lockup is illegible at that size. The desktop header slot uses the horizontal lockup (`wordmark-web.png`) instead of the emblem-only crest.
